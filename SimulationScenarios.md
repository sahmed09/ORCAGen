# Description of Simulation Scenarios

| Malware Family | Technique | PoC Description | PoC Code Link | Orchestration Strategy | Orchestration Code Link |
| -------------- | --------- | --------------- | -------------- | ---------------------- | ----------------------- |
| Keylogger | Screen Logging | Captures periodic screenshots using screen capture APIs like `BitBlt` or `PrintWindow` to monitor user activity. |  | Hooks screen capture APIs (e.g., `BitBlt`) via EasyHook to inject decoy images during malicious capture attempts, while allowing legitimate screen captures to function normally. | |
| Keylogger | Mouse Tracking | Tracks mouse movement periodically using APIs like `GetCursorPos` to monitor cursor behavior. |  | Hooks `GetCursorPos` via EasyHook to block tracking attempts by returning a predefined block message, while preserving functionality for legitimate applications. |  |
| Keylogger | Clipboard Logging | Monitors and captures clipboard content such as copied text or sensitive data using APIs like `GetClipboardData`. |  | Hooks `GetClipboardData` via EasyHook to return decoy clipboard content during malicious access attempts, while allowing normal clipboard use for legitimate applications. |  |
| Keylogger | Keyboard Hooking | Polls keyboard state at at short intervals (much shorter than one second) using `GetAsyncKeyState` to detect and log keystrokes. |  | Hooks `GetAsyncKeyState` via EasyHook to inject false keystrokes (e.g., repeated "t" characters) into the keylogger's logs, while maintaining normal keyboard functionality for legitimate applications. |  |
| Keylogger | Screen Logging | Captures periodic screenshots using screen capture APIs like `BitBlt` to monitor user activity. |  | Hooks `BitBlt` via EasyHook to simulate screenshot success while blocking the actual screenshot capture (FakeFailure), ensuring normal operation for authorized screen capture tools. |  |
| Ransomware | File-Based Encryption (FakeFailure) | Encrypts selected user file types (e.g., `.docx`, `.xlsx`, `.db`, `.txt`) using APIs like `CreateFile`, `ReadFile`, and `WriteFile` after discovering them with `FindFirstFile`/`FindNextFile` while skipping critical operating system and application files to keep the system functional. |  | Hooks file operation APIs such as `CreateFile`, `WriteFile`, `SetFilePointer`, and `FlushFileBuffers` via EasyHook to block actual encryption and return FakeFailure responses, making the ransomware believe encryption failed. Legitimate file access remains unaffected. |  |
| Ransomware | File-Based Encryption (FakeSuccess) | Encrypts selected user file types (e.g., `.docx`, `.xlsx`, `.db`, `.txt`) using APIs like `CreateFile`, `ReadFile`, and `WriteFile` after discovering them with `FindFirstFile`/`FindNextFile` while skipping critical operating system and application files to keep the system functional. |  | Hooks file access and write APIs such as `CreateFile`, `WriteFile`, `SetFilePointer`, and `FlushFileBuffers` via EasyHook to simulate FakeSuccess encryption without altering file content. The ransomware perceives encryption as complete, while files remain safe and intact. Legitimate file access remains unaffected. |  |
| Ransomware | File Renaming or Extension Changes (FakeSuccess) | Appends or modifies file extensions (e.g., `.locked`, `.REvil`, `.encrypted`) in a given directory after encryption using `MoveFile` or `MoveFileEx`. |  | Hooks file renaming APIs such as `MoveFile` and `MoveFileEx` via EasyHook to detect suspicious extensions and block renames. Returns FakeSuccess responses to deceive ransomware, while allowing normal renaming functionality for trusted applications. |  |
| Ransomware | File Renaming or Extension Changes (FakeFailure) | Appends or modifies file extensions (e.g., `.locked`, `.REvil`, `.encrypted`) in a given directory after encryption using `MoveFile` or `MoveFileEx`. |  | Hooks file renaming APIs such as `MoveFile` and `MoveFileEx` via EasyHook to detect suspicious extensions and block renames. Returns FakeFailure responses to deceive ransomware, while allowing normal renaming functionality for trusted applications. |  |
| Ransomware | File Renaming or Extension Changes (Block) | Appends or modifies file extensions (e.g., `.locked`, `.REvil`, `.encrypted`) in a given directory after encryption using `MoveFile` or `MoveFileEx`. |  | Hooks file renaming APIs such as `MoveFile` and `MoveFileEx` via EasyHook to monitor and directly block renaming operations involving known ransomware extensions. Normal file renaming functionality for non-suspicious extensions remains operational. |  |
| Information Stealer | File System Scanning (FakeSuccess) | Recursively scans directories to locate sensitive files based on target extensions and filenames (e.g., `wallet.dat`, `api_key`, `.json`, `.ini`, `.conf`, `.txt`, `browser profiles`) using Windows APIs like `FindFirstFile`. |  | Hooks file scanning APIs such as `FindFirstFile` via EasyHook to replace search results with decoy filenames. Deceives malware with FakeSuccess approach while protecting real files. Legitimate file system access remains unaffected. |  |
| Information Stealer | File System Scanning (FakeFailure) | Recursively scans directories to locate sensitive files based on target extensions and filenames (e.g., `wallet.dat`, `api_key`, `.json`, `.ini`, `.conf`, `.txt`, `browser profiles`) using Windows APIs like `FindFirstFile`. |  | Hooks file scanning APIs such as `FindFirstFile` via EasyHook to return FakeFailure response during malicious searches. The malware is misled to believe no files exist, while normal application behavior remains unaffected. |  |
| Information Stealer | Registry Mining (Decoy Data) | Queries sensitive registry keys (e.g., Winlogon\DefaultPassword) to extract auto-login credentials and other stored data using Windows APIs such as `RegOpenKeyEx` and `RegQueryValueEx` on both 32-bit and 64-bit operating systems. |  | Hooks registry access APIs such as `RegOpenKeyEx`, and `RegQueryValueEx` via EasyHook to redirect malware queries to decoy registry values. Real data is protected, ensuring normal registry access functionality is unaffected. |  |
| Information Stealer | Registry Mining (FakeSuccess) | Queries sensitive registry keys (e.g., Winlogon\DefaultPassword) to extract auto-login credentials and other stored data using Windows APIs such as `RegOpenKeyEx` and `RegQueryValueEx` on both 32-bit and 64-bit operating systems. |  | Hooks registry access APIs such as `RegOpenKeyEx`, and `RegQueryValueEx` via EasyHook to simulate a successful read operation while returning no actual data. The malware receives a FakeSuccess response, while legitimate registry access remains unaffected. |  |
| Information Stealer | Registry Mining (FakeFailure) | Queries sensitive registry keys (e.g., Winlogon\DefaultPassword) to extract auto-login credentials and other stored data using Windows APIs such as `RegOpenKeyEx` and `RegQueryValueEx` on both 32-bit and 64-bit operating systems. |  | Hooks registry access APIs such as `RegOpenKeyEx`, and `RegQueryValueEx` via EasyHook to return failure errors while returning no actual data. The malware receives a FakeFailure response when attempts to extract registry data, while legitimate registry access remains unaffected. |  |
